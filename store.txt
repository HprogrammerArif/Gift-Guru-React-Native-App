## 📋 Google Play Policies for GiftGuru (Amazon Affiliate App)

---

### ⚠️ Key Policies You Must Follow

#### 1. **Affiliate Links Policy**
| Rule | What It Means for GiftGuru |
|---|---|
| ✅ Amazon links for **physical products** = ALLOWED | GiftGuru shows gift products → OK |
| ❌ Links opening inside **WebView** = BANNED | Must open in external browser (Chrome, etc.) |
| ❌ App that is **just a link wrapper** = BANNED | Must have genuine social/community features |
| ✅ Clearly disclose affiliate links to users | Add "Contains affiliate links" note in app |
| ❌ Disguising affiliate links = BANNED | Don't hide that links go to Amazon |

#### 2. **Subscription/Billing Policy**
| Rule | Status |
|---|---|
| Premium features must use Google Play Billing | ✅ You're using RevenueCat → Google Play Billing |
| Free users must still access basic features | ⚠️ Make sure free tier exists |
| Amazon purchases happen outside the app | ✅ Opens browser → Google doesn't take cut |

#### 3. **Amazon Associates Rules**
| Rule | What To Do |
|---|---|
| No WebViews of Amazon pages | Use `Linking.openURL()` in React Native |
| App must have original content | ✅ Your social platform features cover this |
| Don't copy Amazon's app functionality | Keep it social/gift-focused, not a shop clone |
| Affiliate links must be free to access | ⚠️ Don't lock affiliate links behind paywall |
